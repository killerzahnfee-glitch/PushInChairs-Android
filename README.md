# PushInChairs Android – experimentell

Ziel: Stardew Valley 1.6.15.3 Android, SMAPI 4.3.2.5.

Nur Möbel vom Typ `Furniture.chair` werden bewegt. `Furniture.table` und `Furniture.longTable` dienen ausschließlich als Bezugspunkte. Sofas, Couches, Sessel, Schränke und andere Möbel bleiben unverändert.

**Noch keine fertige Mod:** Die erste Implementierung verschiebt einen Stuhl nur auf ein freies Nachbarfeld in Tisch-Nähe, nicht unter den Tisch. Android-Kompatibilität und Kompilierung sind noch nicht bestätigt. GitHub Actions versucht bei jedem Push einen Build und lädt bei Erfolg ein ZIP-Artefakt hoch.
